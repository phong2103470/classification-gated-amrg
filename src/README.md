# Đặc tả dữ liệu thực nghiệm (`data/`)

Hai bộ dữ liệu X-quang ngực công khai chuẩn được sử dụng để đánh giá:
- **IU-Xray:** 7.470 ảnh (2.069 ca huấn luyện), ghép cặp ảnh đa góc nhìn (Thẳng + Nghiêng).
- **MIMIC-CXR:** 377.110 ảnh X-quang ngực, áp dụng bộ chia chuẩn R2Gen và hệ 55 nhãn giải phẫu từ RadGraph-XL / SRRG.
